# Render.com Deployment Guide (Free Tier)

## Why Render?
- ✅ **Free tier**: 750 hours/month (enough for 24/7 uptime)
- ✅ **No credit card required** for free tier
- ✅ **Auto-deploy** from GitHub
- ✅ **Works with MongoDB Atlas**
- ✅ **Free SSL** and custom domains

---

## Step 1: Create Render Account
1. Go to https://render.com/
2. Sign up with GitHub (use the same account where you pushed the repo)
3. Authorize Render to access your repositories

---

## Step 2: Create Web Service
1. Click "New +" → "Web Service"
2. Connect your GitHub repository: `hetcharusat/ratesangeet`
3. Render will detect the `render.yaml` file automatically

**Or manually configure:**
- **Name**: spotirate-api
- **Region**: Singapore (or closest to you)
- **Branch**: dev
- **Root Directory**: (leave empty)
- **Runtime**: Node
- **Build Command**: `cd server && npm install && npm run build`
- **Start Command**: `cd server && npm start`
- **Plan**: Free

---

## Step 3: Configure Environment Variables
Click "Environment" tab and add these variables:

### Required Variables (add manually):

```
MONGODB_URI=mongodb+srv://<user>:<pass>@<cluster>/spotify-tracker?retryWrites=true&w=majority&appName=SpotifyTracker
SPOTIFY_CLIENT_ID=30d78a30cd9f435eba6edbaa4a427041
SPOTIFY_CLIENT_SECRET=<your_spotify_client_secret_optional>
SPOTIFY_REDIRECT_URI_WEB=https://YOUR_RENDER_DOMAIN/api/auth/callback
SPOTIFY_REDIRECT_URI=https://YOUR_RENDER_DOMAIN/api/auth/callback
```

### Auto-configured (from render.yaml):
- `NODE_ENV=production`
- `PORT=10000`
- `SPOTIFY_REDIRECT_URI_MOBILE=ratesangeet://callback`
- `SESSION_SECRET=<auto-generated>`
- `CLOUD_ENABLE_SCROBBLES=false`
- `ARCHIVE_RETENTION_DAYS=90`
- `ARCHIVE_KEEP_RECENT=200`

**Important:**
- Replace `<user>:<pass>@<cluster>` with your MongoDB Atlas credentials
- Get `MONGODB_URI` from Atlas: Database → Connect → Drivers → Connection String
- Replace `YOUR_RENDER_DOMAIN` after deployment (step 5)

---

## Step 4: Deploy
1. Click "Create Web Service"
2. Render will:
   - Clone your repo
   - Run build command
   - Start the service
3. Watch logs in the dashboard (takes 2-5 minutes)

---

## Step 5: Get Your Domain
After deployment succeeds:
1. Copy your Render URL from the dashboard (e.g., `https://spotirate-api.onrender.com`)
2. Update environment variables:
   - `SPOTIFY_REDIRECT_URI_WEB=https://spotirate-api.onrender.com/api/auth/callback`
   - `SPOTIFY_REDIRECT_URI=https://spotirate-api.onrender.com/api/auth/callback`
3. Click "Manual Deploy" → "Clear build cache & deploy"

---

## Step 6: Update Spotify Dashboard
1. Go to https://developer.spotify.com/dashboard
2. Edit your Spotify app
3. Add Redirect URIs:
   - `ratesangeet://callback` (mobile)
   - `https://spotirate-api.onrender.com/api/auth/callback` (web)
4. Save changes

---

## Step 7: Test Deployment
Test these endpoints in your browser or PowerShell:

```powershell
# Health check
curl https://spotirate-api.onrender.com/api/health

# Web login
curl https://spotirate-api.onrender.com/api/auth/login?target=web

# Mobile login
curl https://spotirate-api.onrender.com/api/auth/login?target=mobile
```

All should return JSON responses.

---

## Step 8: Build Mobile APK
Once your backend is live, build the APK pointing to your Render domain:

```powershell
cd mobile
$env:EXPO_PUBLIC_API_URL="https://spotirate-api.onrender.com/api"
eas build --platform android --profile preview
```

## Troubleshooting

### Build Fails
- Check logs in Render dashboard
- Verify `server/package.json` has `build` and `start` scripts
- Ensure `tsconfig.json` is valid

### MongoDB Connection Error
- Verify `MONGODB_URI` is correct (copy from Atlas)
- Check Atlas Network Access: allow 0.0.0.0/0 (all IPs) for free tier
- Ensure database user has read/write permissions

### Spotify Auth Fails
- Verify redirect URIs in Spotify dashboard **exactly match** env vars
- Check `SPOTIFY_CLIENT_ID` matches your Spotify app
- For web flow: ensure `SPOTIFY_CLIENT_SECRET` is set

### Service Sleeps (Free Tier)
- Free tier services sleep after 15 minutes of inactivity
- First request after sleep takes ~30 seconds to wake up
- Upgrade to paid tier ($7/month) for always-on
