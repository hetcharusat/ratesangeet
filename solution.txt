### ✅ Full implementation: Spotify OAuth (Expo + AuthSession Proxy)

**Dependencies (run this):**

```bash
npx expo install expo-auth-session expo-web-browser expo-crypto
```

---

**App.js**

```js
import React, { useEffect } from 'react';
import { Button, View, Text } from 'react-native';
import * as WebBrowser from 'expo-web-browser';
import * as AuthSession from 'expo-auth-session';

WebBrowser.maybeCompleteAuthSession();

const discovery = {
  authorizationEndpoint: 'https://accounts.spotify.com/authorize',
  tokenEndpoint: 'https://accounts.spotify.com/api/token',
};

export default function App() {
  // 1. Proper redirect URI with Expo proxy (no localhost or 127.0.0.1 nonsense)
  const redirectUri = AuthSession.makeRedirectUri({
    useProxy: true,
  });

  // 2. Create the OAuth request (PKCE included automatically)
  const [request, response, promptAsync] = AuthSession.useAuthRequest(
    {
      clientId: 'YOUR_SPOTIFY_CLIENT_ID',
      scopes: ['user-read-email', 'user-read-playback-state'],
      redirectUri,
      usePKCE: true,
      responseType: 'code',
    },
    discovery
  );

  // 3. Handle Spotify’s response
  useEffect(() => {
    if (response?.type === 'success') {
      const { code } = response.params;
      console.log('Authorization code:', code);
      // If you have a backend, send this code to it for token exchange.
      // Otherwise, you can directly fetch access_token here (PKCE).
    }
  }, [response]);

  return (
    <View style={{ flex: 1, justifyContent: 'center', alignItems: 'center' }}>
      <Text>Spotify OAuth (Expo AuthSession)</Text>
      <Button
        disabled={!request}
        title="Login with Spotify"
        onPress={() => promptAsync({ useProxy: true })}
      />
    </View>
  );
}
```

---

### ⚙️ What this does

* Completely kills the old `http://127.0.0.1` redirect URIs.
* Uses **Expo’s HTTPS proxy** (`https://auth.expo.io/@yourusername/appslug`) automatically.
* Handles **PKCE** for security (Spotify-approved).
* No extra dependencies, no server, no secrets in client.
* Works out of the box in **Expo Go** and dev builds.
