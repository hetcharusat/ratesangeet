ITUE203 - Web Development Framwork - Practical No. 2

==============================================

SETUP INSTRUCTIONS:

1. Databas Setup:
   - Open phpMyAdmin
   - Create new databas: supermarket_inventory
   - Import sql/schema.sql file
   - Done!

2. Configration:
   - Open config/database.php
   - Change databas credentails if needded:
     * $host = "localhost";
     * $db_name = "supermarket_inventory";
     * $username = "root";
     * $password = "";

3. Deploy:
   - Copy supermarket folder to xampp/htdocs
   - Start Apache and MySQL in XAMPP
   - Open browser: http://localhost/supermarket

4. Login:
   - Username: admin
   - Password: admin123

Problem: Alerts not showing
